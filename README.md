# Rebus Solver — Laboratory Work №2

## Описание проекта

Программа для решения числовых ребусов на языке C.

В рамках лабораторной работы реализуется алгоритм поиска решений числовых ребусов и исследуется влияние различных оптимизаций на быстродействие программы.

## Требования

- Каждой букве соответствует уникальная цифра.
- Ведущие нули не допускаются.
- Используется операция сложения.
- Количество слагаемых — от 2 до 7.
- Программа возвращает корректное решение ребуса.

## Компиляция

```bash
gcc -std=c11 -O0 -Wall -Wextra solver.c -o solver
```

## Запуск

Windows:

```powershell
.\solver.exe
```

Linux:

```bash
./solver
```

## История оптимизаций

В процессе лабораторной работы будут реализованы и проверены:

1. Базовый алгоритм полного перебора.
2. Раннее исключение ведущих нулей.
3. Предварительный расчёт коэффициентов букв.
4. Перебор по столбцам с учётом переноса.
5. Использование битовой маски.
6. Эвристики порядка перебора.
